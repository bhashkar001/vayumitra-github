# VayuMitra — Winter Smog & Clean-Air Assistant

A GenAI-powered web assistant helping families and communities navigate severe winter smog and urban air pollution with tailored low-emission routines, indoor air quality hacks, and real-time impact tracking.

## Structure
- `index.html` — Self-contained app (Tailwind CSS, Chart.js, Lucide Icons)
- `assets/` — Custom illustrations (`hero.jpg`, `mascot.jpg`, `community.jpg`)

## Deploy to GitHub Pages
1. Push `index.html`, `README.md`, and `assets/` to your GitHub repository's `main` branch.
2. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch** (`main` / `/ (root)`), and save.
